第一次安装

把扩展加载到 Chrome

先解压 ZIP，再让 Chrome 选择解压后的文件夹。不要直接选择 ZIP，也不要选到文件夹的上一层。

  1. 1

    下载 ZIP，并完整解压

    下载 contact-finder-extension.zip，右键选择「解压」或双击解压，把得到的文件夹放在不会随意删除的位置。

    不要这样做：不要在 ZIP 里直接打开文件，也不要把 ZIP 本身交给 Chrome。

  2. 2

    打开扩展管理

    复制 chrome://extensions/，粘贴到 Chrome 地址栏并按回车。这个地址不能像普通网页链接一样直接点开。

  3. 3

    打开「开发者模式」

    在扩展管理页右上角打开「开发者模式」。开关变成蓝色后，左上方会出现「加载已解压的扩展程序」。

  4. 4

    选择有 manifest.json 的那一层

    点「加载已解压的扩展程序」，选中刚才解压出的文件夹，再点「选择文件夹」。

    选对的标志：打开该文件夹后，第一层就能看到 manifest.json、popup.html。如果只看到另一个同名文件夹，请再进入一层。

  5. 5

    固定到工具栏

    扩展管理页出现「找联系方式」卡片，就是加载成功。点地址栏右侧的扩展菜单，找到它并点图钉，之后可以从工具栏直接打开。

Chrome 扩展管理地址 chrome://extensions/
选择文件夹前，先看这一层 解压后的文件夹 / manifest.json popup.html background.js

第一层能看到 manifest.json，就是 Chrome 要选择的文件夹。

装好就能用

查当前这个网站

打开要查的网页，再点工具栏图标。当前网站会自动开始查找，不用再填什么。

打开

先进入网页

地址以 http 或 https 开头的普通网页才能查。新标签页和扩展管理页不行。

点图标

自动开始查找

窗口打开后就会查。关掉也没关系，工具栏图标会显示进度，再点开就能看结果。

看结果

电话、邮箱、二维码

找到的会分列在窗口里。页面上写明的其他联系方式也会列出来。

在链接上右键

选择「查找这个链接的联系方式」，直接查那个网页。只对 http 和 https 链接有效。

一次贴上很多网址

点窗口里的「批量查找」。每行一个网址或域名，用回车分开，再点「批量查」。

完整网址 只写域名
  1. 打开批量查找在弹出窗口里点「批量查找」
  2. 每行一个example.com 这样写也可以
  3. 点「批量查」窗口里能看到正在查第几个
  4. 在后台进行不会打断你正在看的网页

一般不用填

高级查找口令是选填的

不填也会查找，并点开页面上的联系入口。填了之后，会更准确地打开「联系我们」「关于我们」这类页面，找得更全。

设置 使用帮助
保存
  1. 1

    点窗口右上角的「设置」，会打开单独的设置页。

  2. 2

    把口令贴进输入框，再点「保存」。看到「已保存」就完成了。

  3. 3

    口令向提供这个工具的人索取。申请步骤写在设置页的「使用帮助」里。

口令留在你的 Chrome 里

扩展读取你要查的网页上写明的电话、邮箱、二维码和其他联系方式。要打开的页面在后台标签里。不需要复制 Cookie，也不需要复制登录令牌。

常见问题

多数情况刷新网页，或在扩展管理页里点一次刷新，就能继续用。

提示「请先打开一个网站，再点图标」

先打开一个 http 或 https 网页。新标签页、Chrome 设置页、扩展管理页本身不能查。

提示先关掉开发者工具

这个网站上如果开着开发者工具窗口，先关掉，再点一次图标。

按钮变成「已查过」，不想重新查

这个网站已经查过，而且没有找到联系方式。再点开也不会重新查。

找到的比较少

不填口令也会查。到设置里填上高级查找口令后，会更准确地打开联系页面。口令向提供这个工具的人索取。

关掉窗口之后，还在查吗

还在查。工具栏图标会显示进度：查找中是「…」，出问题是「!」，查完后是找到的条数。再点开图标就能看结果。

批量查找的网址怎么写

每行一个。可以写完整网址，也可以只写域名，比如 example.com。空行会跳过，不是网页地址的也会跳过。

右键菜单里没有这一项

请在 http 或 https 链接上右键，菜单名是「查找这个链接的联系方式」。先确认扩展已经启用。

加载时提示找不到清单文件

选择的文件夹第一层要直接看到 manifest.json。如果只看到另一个文件夹，再进去一层。不要选择 ZIP 本身。

更新之后还是旧的

打开扩展管理页，在「找联系方式」卡片上点刷新。如果换了新的压缩包，先移除旧的，再重新加载解压后的文件夹。

下载之后按步骤加载

解压，打开开发者模式，选择有 manifest.json 的文件夹。
